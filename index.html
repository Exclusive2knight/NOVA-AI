Models & responses

NOVA Pro is a configuration of a hosted open-weight model, not a model with Claude Fable-level intelligence. The exact provider appears in the connection status.

NOVA Pro uses quick reasoning for simple messages by default so a short reply is less likely to spend its entire output allowance thinking. Deep reasoning can consume more quota.

Original NOVA Native model

Our own 50,033-parameter neural classifier, trained from scratch and bundled for fast offline use. Its 17 labels are intent groups, NOT a limit on questions. NOVA can handle many messages, and modular local tools add 14 extra project types without needing a new neural checkpoint. It cannot yet reason or write like a large language model.

Memory & privacy

Opt-in: NOVA saves selected project decisions and preferences you state (not every chat or AI reply) to your Cloudflare database and recalls matching facts in later hosted-AI chats, including on another device with the same Worker and owner passcode. Cloud memory is NOT your model context window and is not the same as local chat history. Never store passwords or private information. You can view, delete or clear memories below.

Cloud memory requires a D1 database and the latest Cloudflare Worker. Click Check cloud memory to verify the connection.

These local notes are included with AI requests. To store them off-device, enable cloud memory and use the button below. Chats and files are also cached locally for this device. This is not model retraining.

Optional answer ratings are stored only here. They are not submitted to any model or training service. Export labels if you want to review them; training examples require separate permission and explicit chosen/rejected responses.
